# Overview

Cents is an Expo (React Native) Android-first mobile app that mirrors the purpose of the web app: fast expense capture with strong security and performance.

## Goals
- Android-first Expo app (Expo Go for dev, EAS for builds).
- Security and performance as first principles.
- Tie into Supabase (auth + data + storage).

## Product Scope (Current)
- Auth (sign up, sign in, reset password)
- Expense tracking with categories
- Dashboard analytics (trend + category breakdown)
- Receipt link support on expenses (scan pipeline to be added)

## Non-Goals (For Now)
- Custom native modules (keep Expo Go compatible)
- Multi-platform release orchestration
