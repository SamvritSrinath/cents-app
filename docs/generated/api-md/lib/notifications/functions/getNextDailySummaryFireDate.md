# Function: getNextDailySummaryFireDate()

> **getNextDailySummaryFireDate**(`hour?`, `minute?`): `Date`

Next local wall-clock fire time at hour:minute (today if still ahead, else tomorrow).

## Parameters

### hour?

`number` = `DEFAULT_SUMMARY_HOUR`

### minute?

`number` = `DEFAULT_SUMMARY_MINUTE`

## Returns

`Date`
