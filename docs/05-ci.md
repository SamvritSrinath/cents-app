# CI

CI runs lint, typecheck, and tests on pull requests. EAS builds are restricted to `main` to limit build credits.

## Workflow
See `/Users/samvrit/Developer/cents-app/.github/workflows/ci.yml`.

## Required Checks (Recommended)
- `lint-and-test`
- Optional: `eas-build` (if you want builds to gate merges)

## Branch Protections (Recommended)
- Require PR reviews (1+)
- Require status checks to pass
- Require linear history
- Disallow force pushes and deletions
